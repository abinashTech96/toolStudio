Setup & compatibility
Start with two browsers
  1. Keep this HTML next to the main Calc Studio HTML. Open Options → Connection.
  2. Open Connection Studio on the other device. Use manual offer/answer exchange or the included signaling helper.
  3. Compare verification codes and approve both screens. Grant only the permissions you need.
Manual pairing exchanges network addresses and encrypted connection fingerprints. Share pairing data only with the intended device. Different networks may require configured STUN/TURN servers; no public relay is bundled.
Optional pairing server
See Connection_Server/README.md in the download package. The helper serves these files and pairing codes; files and messages travel over WebRTC. Use HTTPS/WSS for remote or mobile use. Codes expire after five minutes and have two participants maximum.
Hardware & camera
Camera and USB need a supporting browser, device permission, and usually HTTPS or localhost. WebUSB exposes supported USB interfaces. iPhone/iPad and some TV browsers may not offer these APIs. Unsupported controls explain the limitation. File upload remains available.
Privacy & limits
No account, analytics, saved secrets, background reconnect, or automatic data sharing. One paired device, one inbound and one outbound file at a time; 32 MiB per file, 64 KiB text, 4,000-character messages. Session downloads remain in memory until removed or the page closes. Clear items to release memory. Refreshing clears sessions. This is not desktop screen sharing or a general USB driver.
The original tab needs an explicit bridge grant for remote commands and result sharing. Received text and images always require a separate replacement review. Closing either page revokes its bridge. Existing Calc Studio tools run independently.
