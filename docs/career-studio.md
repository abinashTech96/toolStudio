# Career Studio · v35.05

Open Career & Professional Documents → Career Studio. Studio is the single main category entry. Resume & Applications, Interview & Skills and Portfolio Builder retain their original routes, behavior and data under Overview → Earlier tools & import. Existing favorites and bookmarks still open those editors; they are omitted from ordinary category browsing and Find tools. Unique earlier keyword-matcher, interview-status and JSON-portfolio workflows remain accessible there.

## Create a resume

1. Open Resume → Resume builder. Start with your master profile, the guided prompts, or a reviewed import. Starter examples are clearly fictional and are created as separate variants.
2. Enter contact details and add experience, education, projects and certifications. Optional sections include awards, publications, volunteering, leadership and additional information. Skills can be grouped by category, one group per line.
3. Click a preview section to edit it. Use Edit, Preview or Edit & preview views. Advanced design controls include a template preview gallery, A4/Letter, typography, spacing, page targets, explicit section breaks, language/direction and public-copy field visibility. Section order supports drag and keyboard-accessible move buttons.
4. Review quality findings and plain-text reading order. Structured experience counts overlapping months once; unstructured imported dates remain visible but are not included in that total. Findings are built-in completeness/wording checks, not a universal ATS score or a hiring prediction.
5. Open Export center. Preview actual direct-PDF pages and adjust content/spacing if they exceed the chosen target. Export does not silently trim content.

The live HTML preview is responsive; direct PDF and Word/browser printing can paginate differently. The actual PDF preview renders the bytes used for its download. Direct PDF embeds the bundled DejaVu Sans/Serif fonts and supports covered left-to-right characters. For RTL or scripts outside those fonts, use browser Print / Save as PDF or Word/HTML with an appropriate installed font and review the print preview. Language variants are editable copies. Section order controls include editable output headings; Design also provides translations for Present and project labels. No automatic translation service is configured.

PDF, editable DOCX, HTML and plain-text exports use the selected resume's hidden-field and hidden-section settings. Hiding a name also uses an anonymous HTML/PDF title and default filename. Field hiding does not search and redact mentions inside free text; review bullets and project descriptions before sharing.

## Compact controls and custom alignment

Five primary areas are Overview, Resume, Applications, Interview and Growth. A single Career task selector switches between tasks. Resume secondary actions (including import and undo/redo) live under More resume actions; header help and recovery live under More. Advanced design & sections stays collapsed until needed. Opening Applications does not create a blank record; use Add application deliberately.

Use the editor-width slider (30–70%) and Edit / Preview / Edit & preview modes. Workspace geometry is saved in native projects. Small screens use a single column and a responsive document preview; export margins retain their physical dimensions.

Under Advanced design & sections → Design, language & public-copy controls → Custom alignment & spacing, choose the whole resume or one section. Set body alignment (including justified), name/contact/headings/date alignment, paragraph spacing and bullet indentation. Four individual page margins accept 10–40 mm. Dates remain on their own line. Section overrides take precedence; remove an override to inherit whole-resume settings.

Alignment settings are a draft until Review layout changes → Apply reviewed change. The review shows current/proposed HTML previews, content and visibility differences, and actual direct-PDF page counts. Close cancels. Reset layout is also reviewed and preserves entered facts, language, template and section choices. Source-section updates, checkpoint restoration and template-gallery application use the same review. If direct PDF cannot render a script, review explicitly explains the browser-print/Word path. Inline content edits still update the preview immediately and support undo.

HTML, Word and direct PDF share alignment, indentation and margin settings. Word/browser pagination can differ; the page comparison is specifically for the direct PDF renderer. Justified direct PDF distributes wrapped lines, leaving the final paragraph line naturally aligned. Older v2 projects without new layout fields keep their prior defaults.

## Import and preserve work

Resume import accepts selectable-text PDF, DOCX and TXT up to 10 MB. Review extracted text and editable suggested fields before creating a separate variant. Ambiguous experience/education text is retained under Additional information for manual organization. Resume text extraction/paste supports up to 250,000 characters; a mapped summary, skills or additional-information field above 12,000 characters is explicitly rejected rather than silently shortened. Choose Split into reviewable parts to assign the complete text to bounded experience/education entries or shorter summary, skills and additional-information fields. Original text is retained in the imported variant and remains visible under Versions & content. Repeated lines and missing/uncertain fields are flagged for review; they are not automatically deleted or corrected. The source text remains visible and current project data is unchanged. Scanned PDFs need OCR in Camera & Image Studio, followed by pasted-text review. The original tool has limits on OCR accuracy; review the result.

Project & recovery accepts a native Studio v2 project or the original v1 career project. Original migration retains the full original payload, including matcher inputs and old text versions, in a downloadable original project; structured profile, experience, education, evidence, interview notes and skills are mapped into Studio. It leaves the original tools' in-memory data unchanged. Review before applying. Native project limit is 12 MB; resume variants are limited to 30, named checkpoints to 12, and most record lists to 200. Project screenshot uploads are limited to 150 KB each.

Master-profile edits do not silently overwrite variants. Compare against a source under Versions & content and apply individual sections after review. Checkpoints and undo/redo provide recovery from editing and template changes. Removing a resume linked to an application requires choosing another resume for that application first. Evidence referenced by a requirement or appraisal must be unlinked before removal.

## Track applications and prepare

- Add an application with its job description, recruiter, dates, status and selected resume. Its live checklist links details, requirement/evidence review, the selected resume, linked documents, a submitted snapshot, follow-up dates and interview preparation. These are observable preparation steps, not a readiness score; some may be optional for your application. Overdue follow-ups are shown without claiming system notifications. Use Kanban, table or monthly calendar views; stages also have a select control for keyboard/touch use.
- Tailor a separate resume from that application. Review and mark a submitted copy: it stores an independent document/settings snapshot. Further edits preserve that exact submitted copy.
- Review requirement lines before adding them. Link achievements or supporting notes, choose explicit coverage states and turn uncovered requirements into learning actions. Literal text and self-entered coverage are not qualification verification.
- Add interview questions or use the curated general/Salesforce starter pack. Practise an answer with a timer, reveal notes/follow-up questions and save actual responses with transparent self-review ratings. Mark questions for more practice and compare saved attempts side by side. Open-ended AI coaching is not configured.
- Track learning tasks, deadlines, self-rated levels and evidence. Select achievements for an editable appraisal/promotion draft. These drafts use supplied facts and do not verify metrics.

## Documents, portfolio and offers

Professional documents include introductions, cover letters, referrals, recruiter replies, interview follow-ups, offer clarification, resignation, handover, project updates, appreciation and appraisals. Structured drafts use entered context, are reviewed before replacement and support saved versions, text, Word, HTML and PDF export. Each document can keep a separately reviewed alignment layout; changing it leaves the master resume unchanged.

The portfolio uses selected projects from the master profile, with form-based case studies, per-project screenshots, ordering, preview and a standalone HTML export. It preserves the original Portfolio Builder as a separate tool.

Review an application's document-bundle contents before exporting. It uses the submitted resume snapshot where available and otherwise the linked current resume. Bundles contain HTML/text/Word resumes, linked document drafts and an application summary; they are not sent automatically.

Offer comparison displays fixed recurring pay, expected variable pay, first-year value and user-weighted preference scores. Expected variable = full variable × chosen payout percentage. First year = fixed + expected variable + joining bonus + the entered benefits valuation. Benefits may be non-cash. Different currencies are not converted or ranked; no tax or take-home calculations are claimed.

## Saving, offline use and validation

Session-only is the default. Export project for a portable copy of all Studio data. Optional local recovery writes only after explicit enablement and reports save failures. Existing recovery or another tab's changes must be reviewed before adoption/replacement. Recovery is registered with the application's reset/storage controls; original career exports remain independent. Project files contain the details and notes you enter.

Hosted heavy engines/fonts load on demand. The standalone offline HTML embeds Career Studio, its engines and fonts. Browser print and locally installed fonts remain browser/device dependent.

Run npm run test:career and all existing project suites. Career tests cover original-project migration, isolation, variants, submitted snapshots, requirements/evidence, practice, growth, appraisals, documents, portfolio, actual PDF and OOXML content, import round trips, recovery conflicts, responsive layout and accessibility. External recruitment platforms and optional AI services are not contacted.
