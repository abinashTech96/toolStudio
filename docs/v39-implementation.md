# Existing-system improvements · v39

This changes existing workspaces and retains all 69 workspaces, 124 routes, and 105 original routes. The item-by-item source and regression mapping is in `v39-backlog.json`. Draft PR #10 is not deployment approval.

## Controls and recovery

A single task picker selects existing tools and guided work. Secondary workspace actions live in More actions, with independent phone, tablet and desktop presentation preferences. Searchable selects retain their original options and handlers. Validation provides a button that opens and focuses the affected input.

The project centre reports capacity and offers optional IndexedDB recovery for shared records and real reusable-file bytes. Restore reviews conflicts per record, checks file hashes and capacity before applying, and rejects a stale revision or another tab's newer recovery token. The portable bundle can include selected shared records, datasets, files, saved guided inputs and layouts. Imported records become separate copies.

Session secret variables have password entry and explicit destination review. Their values are redacted from shared records, portable bundles, recovery and text drafts. Detected credential fields are also masked; files are byte-preserving and should be reviewed before sharing. Recovery is an opt-in local copy, not a remote account sync.

## Data, developer and research

CSV preview accepts comma, semicolon, tab and pipe, header-free data, UTF-8/UTF-16/Windows-1252, and preserves multiline quoted fields. Limits remain explicit: 4 MB, 50,000 rows and 200 columns. Applying to the existing Workbench retains its smaller existing limit and Undo. Correction selection checks each before-value and preserves unchecked cells. Join preview estimates many-to-many expansion, unmatched rows and duplicate keys without executing the join.

Request baselines show method, URL, header and body differences; changed secrets remain visible as changes with redacted values. Existing endpoint approval is still required to send. Mapping explanations use supplied Salesforce metadata. Request/log correlation matches supplied literal IDs and bounds preview size. Translation findings navigate to the existing target editor.

BibTeX import previews nested values, string macros, concatenation, author lists and publication metadata before explicit replacement. Unsupported TeX commands remain visible for human correction; this is not a full TeX interpreter or publisher style validator.

## Career and files

PDF font coverage can be checked before export. A covered custom TTF/OTF font up to 8 MB can be selected for the current PDF session. Direct PDF uses bidirectional embedding runs and contextual glyph shaping for covered Arabic/Hebrew text, with ActualText and embedded fonts. This path relies on the pinned pdf-lib/fontkit subset interface and has a regression contract. Other scripts still require coverage and visual review. Word uses its own font selection; font coverage does not promise identical pagination.

PDF/Word exports include safe HTTP(S) and email hyperlinks. Export consistency shows the common document blocks and whether current preview bytes will be downloaded. PDF import offers source order, across-row order, or midpoint-based left-column/right-column order. Original extracted text remains reviewable; irregular layouts need manual correction. Import extraction and actual PDF preview can be cancelled.

PDF comparison accepts explicit unique original/revised page pairs, including null for additions/removals. Every page must appear. Review comments anchor to original page numbers; inserted revised pages are identified separately because they have no original anchor.

Image layer width/height now affect actual raster drawing. OCR can reprocess a selected rectangle, review the merged words and preserve corrections outside that rectangle. Applying reconstructs word spacing; inspect the preview. Batch outputs retain successful files, support failed-only retries, enforce a combined output limit, and discard late cancelled results. The original raster encoder is isolated behind an adapter that releases temporary canvases on success, failure and cancellation.

## Connection, calculation and regression

BLE operations and USB opening/transfers have deadlines and discard late results. Disconnect frees notification handlers and capability controls reflect the selected characteristic or endpoint. Up to ten explicitly saved profiles contain BLE/USB parameters, never payloads, permissions or credentials. Applying fills controls without connecting. Session traces retain 200 byte-count summaries with transport filtering; payloads are excluded. Permission and device errors include a concrete next action.

Math/finance workspaces can pin five in-tab calculation scenarios, compare input and visible-output snapshots, restore selected inputs and export structured records with mode, units and precision notes. These snapshots do not certify that a legacy visible result was recomputed: run the tool before capture.

Repayment defaults remain two decimal places and nearest rounding. Optional 0–4 decimal places, half-even and directed rounding flow through projection and statement reconciliation. Kanban sync accepts explicit status-to-column IDs, validates completed-column semantics, preflights all rows and uses the original transaction/Undo. Weekly planning reports entered capacity alongside capacity from configured weekends, holidays and hours per working day.

CI validates pull requests and main pushes without duplicate feature-branch push runs. New browser fixtures execute a representative result in every category, preserve real v36/v37/v38 schema fixtures, exercise conflict and portable-file recovery, simulated hardware deadlines, and regional OCR.
