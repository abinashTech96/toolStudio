PDF Form Filler

Fill standard AcroForm text fields, checkboxes, dropdowns and radio groups. Keep fields editable or flatten the output.

Scanned documents and XFA forms are not supported. The bundled standard font supports Latin text; characters outside its encoding are reported before export.

PDF Workspace

Organise PDF pages or fill standard PDF forms. Each mode retains its original controls.

PDF toolkit

Set page order with ranges such as 3,1,5-7 or 4-2. Blank selects all pages; repeats duplicate pages. Move files up/down to change merge order. Encrypted PDFs are unsupported. Up to 20 files / 50 MB combined / 1,000 input and output pages. Editing rewrites the document and does not preserve digital signatures, bookmarks, or interactive forms.
