Live API client

Build and send HTTP requests, inspect responses, and organise reusable requests. Nothing is sent until you choose Send (Ctrl/⌘ Enter).

Cross-site cookies remain subject to browser and server policies. Redirects are followed using the browser’s normal rules.

Parameters are URL-encoded and appended to the URL. Repeated names are allowed.

Content-Type is set automatically for JSON and form bodies unless you provide it. Browser-controlled headers such as Host, Cookie and Content-Length cannot be set here.

Authentication is held in this tab. It is omitted from saved/exported requests unless explicitly included. Clear the request to remove it.

GET and HEAD cannot have a request body. JSON is validated without changing number precision. Limit: 2 MiB of body text.

Collections & saved requests

Save includes the entered URL, query and body. Authentication values and sensitive headers/query values are removed by default; variable placeholders are retained. Review request bodies before sharing. Export contains all saved requests and remembered environment values.

Environment variables

Use {{base_url}} or {{token}} in the URL, query, headers, authentication or body. Values are kept in this tab unless you choose Remember. Environment edits take effect after Save / apply.

Request history

History stores method, endpoint, status and timing only. Query strings, request/response bodies and authentication are not retained. Use endpoint loads it for editing; it does not resend.

Browser access & troubleshooting

This client sends requests directly from your browser. The API must allow your app’s origin through CORS. Opening this file directly can produce a null origin; serving it on localhost provides a normal origin, but the API must still allow it. A browser cannot expose every network/TLS/CORS error or every response header. For APIs that reject browser access, use the generated cURL command in an external client. Request building, collections and environments remain available offline.
