Regex tester

JavaScript regular expressions. Test explicitly; patterns are not run while typing.

g = all matches; i = case insensitive; m = multiline anchors; s = dot includes newlines; u = Unicode; y = sticky. Match positions use UTF-16 units. Up to 500 matches; text up to 200,000 units; 2-second timeout. Replacement supports $&, $1, and named groups. Replacement output is capped at 2 Mi units.
