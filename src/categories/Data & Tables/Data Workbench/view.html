Data Workbench

Import, edit, clean and export a table. CSV values stay text by default; JSON types are preserved. Undo and redo every data change.

Up to 10,000 rows / 200 columns; 100 visible rows per page. Sort by clicking a column heading. Excel export contains values, not recalculated formulas. CSV export protects formula-like text.

JSON → CSV

Paste an array of records or select an array inside an object with /records.

Columns use escaped JSON Pointer paths. Arrays stay as JSON in a cell; null/missing fields are empty. Spreadsheet protection prefixes risky string cells with an apostrophe. JSON numbers retain their exact spelling; spreadsheets may still round them when importing as numbers.

CSV → JSON

Quoted fields, multiline cells, escaped quotes and CRLF are supported. Values stay strings unless detection is enabled. Large numeric tokens remain intact.

Sample data generator

Synthetic data only. Types: sequence, name, email, integer, decimal, boolean, choice, date, uuid, text, null. Email addresses use example.com. Fields are literal keys.
