JSON Studio

One source, multiple JSON operations. Results become the shared source only when you choose Use result as input. Existing operation options remain available.

JSON formatter

Paste JSON or upload a text/JSON file. Large integers and original numeric values are preserved.

Strict JSON: double-quoted strings, no comments or trailing commas. Duplicate keys are preserved and reported. Files and text stay in this page; they are not added to automatic storage or backups.

JSON explorer

Expand a node to inspect nested fields. Copy path uses JSON Pointer notation.

JSON Schema validator

Offline Ajv validation: draft-07 (default) or draft-2020-12 via $schema. Local references and standard formats are supported; remote schemas are not fetched. Data is never coerced or modified.

Numbers that would lose their JSON precision are rejected before validation. Numeric constraints use JavaScript arithmetic. Complex schemas stop after 3 seconds; up to 200 errors are shown.

JSON field masker

Key names match at any depth; /paths use JSON Pointer with * for one level. Review the output before sharing: only selected fields are masked.

JSON mapping tool

Sources use JSON Pointers; destinations create nested objects. Conversions: copy, string, number, boolean. Untouched numeric tokens remain precise.

JSONPath query tool

Supports $, fields, quoted fields, array indexes, *, recursive descent and simple existence/comparison filters. No scripts, unions, slices or functions.
