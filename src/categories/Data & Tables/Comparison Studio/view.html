Reconciliation Studio

Match two tables by one or more key columns. Duplicate or blank keys are reported separately; ambiguous records are never paired automatically.

Tolerance applies only when both values are valid decimal numbers. Leading-zero IDs remain text. Reports include source row numbers and the comparison rules.

Comparison Studio

Compare text, JSON, XML or workbooks, and reconcile records. Filter changes, review both sides and export your selection.

JSON difference

Paste or upload both inputs. Object key order is ignored; array positions are significant.

Paths use JSON Pointer notation: /items/0/name. Arrays are compared by index, not by item identity. Duplicate keys must be resolved before comparison. Editor contents are not automatically saved or included in backups.

Text difference

Compare lines of text, logs, or code. Added and removed lines retain their line numbers.

XML formatter & difference

Well-formedness and structural comparison only, not XSD validation. Mixed content retained; DTD/entity declarations are rejected.

Excel viewer & comparator

Preview is paginated. Compare by a unique key in the first row. Cells use stored values; formulas are not recalculated or executed. Files stay in this page. Limits: 20 MB per workbook, 10,000 data rows and 200 columns per sheet.
