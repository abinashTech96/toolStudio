Text Toolkit

Count, transform and encode text using a shared source with explicit result reuse and undo.

Character count

Counts include spaces and line breaks unless stated otherwise. Emoji-aware character counting is separate from Unicode code points and UTF-16 units.

URL / Base64

URL component encodes reserved separators. Full URI preserves separators such as : / ? &. Base64 supports emoji and Unicode text.

Base64URL uses - and _ without padding. Decoding accepts optional padding and whitespace but rejects invalid data or non-UTF-8 binary content. URL decoding does not turn + into a space. Input is limited to 2 Mi UTF-16 units.

Text utilities

Line tools normalize line endings to LF. Find/replace treats both inputs literally, including $ characters.
