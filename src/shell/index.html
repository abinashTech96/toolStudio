Guide & shortcuts

Edition 10: 67 tools. New: ZIP archives, flowcharts, IPv4/IPv6 subnets, secure passwords/passphrases, barcodes, calendar ICS events, and image color picking. Category scopes the tool dropdown; Find tool lists every tool together. Options holds secondary controls. History is a collapsible drawer with a desktop width slider. Paired editors have a desktop divider and mobile input/output buttons. Background tasks offer Cancel; ZIP steps also report progress. Switching tools stops the active worker.

ZIP: up to 50 MiB opened / 100 MiB expanded, 2,000 entries, 500 selected files; stored/Deflate only, no encrypted or ZIP64 archives. Diagrams: a dedicated text/JSON language, up to 150 nodes / 300 edges; drag or use arrow keys to move nodes. Passwords use browser cryptographic randomness and are never saved. Calendar recurrence is finite, up to 366 occurrences, with explicit timezone-aware dates; all-day end is exclusive. Image palettes are approximate. The included README has detailed workflows, bounds, and browser support notes.

The preceding edition adds Excel viewing/comparison, QR generation/reading, image editing, PDF merge/split/reorder/rotation, colors/contrast, interest rate solving, number-to-words, payment identifier checks, decision matrices, typing practice, expense splitting, file inspection, and saved URL shortcuts. All libraries are bundled into this single HTML file. New uploads stay page-local; URL shortcuts persist separately and have their own export/import.

Edition 8 adds Composite/Graph building, API response analysis, mapping, JSONPath, XML comparison, integration test generation, business-day deadlines and public-key JWT verification. Log analysis adds reference comparisons, correlations, filters, rules and operation trees. Open Editor controls for heights, collapsed inputs/options, pane divider, uploads and Send to tool; Undo last transfer restores the previous destination.

Edition 7 adds advanced log analysis, JSON field masking, API request construction, JWT inspection, SOQL formatting, Cron building, sample data, and Markdown preview. Log findings distinguish reported evidence from heuristics and missing coverage. All source data stays in this page.

Choose a category first, then its tool in the second dropdown. Find tool remains a flat list of all 67 workspaces. Recent shortcuts remember six tools. Full screen expands the working area; Esc closes it. Edition 6 adds Text difference, CSV → JSON, JSON explorer, Salesforce ID conversion, UUIDs, SHA-256, Text utilities, and JSON Schema validation.

Character count, JSON formatter, and JSON difference are in the workspace dropdown and Find tool. JSON tools accept pasted text and .txt/.json uploads, with copy/download output. Developer editor contents are page-local and excluded from automatic storage and full backups.

Edition 3 adds named notebook sessions, full JSON backup/restore, display formatting, feet–inches measurements, matrices/vectors, numerical calculus, custom conversion presets, and history labels/notes/pins. Settings are in Formatting & backup.

Ctrl/Cmd + Z undoes a supported text edit; Ctrl/Cmd + Shift + Z or Y redoes it. Ctrl/Cmd + Alt + N opens Notebook; Ctrl/Cmd + Alt + H toggles History; Ctrl/Cmd + Alt + S exports a full backup. The arrow buttons undo/redo the last focused editor. Notebook editor width is adjustable on larger screens.

Choose a workspace from the dropdown. Use ☆ to favorite it, Find tool or Ctrl/Cmd + K to search, and Expand / Compact to switch layouts. History is available from the top bar.

Notebook supports named variables; Graph plots up to four expressions in x. Equation solver provides coefficient-based linear/quadratic/system solutions. Fractions provides exact rational arithmetic and selected radical / pi forms. Date tools, Finance, Programmer, and Saved formulas have dedicated workspaces. See the included README for examples and limits.

Expressions: 2(3+4), 2^3^2, sqrt(81), log(100), log(8,2), root(27,3), 5!, nCr(10,3), nPr(5,2), mod(17,5). Function names are case insensitive.

Trig functions and their inverses follow DEG / RAD. Powers are right associative: 2^3^2 = 512; -2^2 = -4. Real numbers only.

20% = 0.2. For a 20% increase use 100 × (1 + 20%), or Quick tools → Percentages.

Function buttons wrap selected text; otherwise they insert an editable function. History restores expressions, angle mode, and the answer used by Ans. Memory, themes, and history save in this browser when storage is available.

Results use standard floating point arithmetic, displayed to 14 significant digits. This is suitable for general calculations; small rounding differences are possible.
