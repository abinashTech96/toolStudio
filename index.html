Feet & inches
Examples: 12 ft 6 in, 12' 6", 6 1/2 in, 3.5 m, 220 cm. Bare numbers mean feet. Results are approximate; area and volume require nonnegative dimensions.


Matrices & vectors
Up to 8 × 8 matrices. Entries are decimal/scientific numbers. Dot product flattens entries into a vector; cross product requires exactly three entries. Near-singular inverses may be unstable.


Numerical calculus
Numerical estimates, not symbolic derivatives or integrals. Error estimates are approximate. Functions with singularities, jumps, or rapid oscillations may fail or produce unreliable estimates.


Conversion presets
Custom units use a positive multiplication factor; they do not support offsets. Use built-in temperature conversion for °C/°F/K. Currency presets save the pair, not a fixed exchange rate.

Character count

JSON formatter
Paste JSON or upload a text/JSON file. Large integers and original numeric values are preserved.
Strict JSON: double-quoted strings, no comments or trailing commas. Duplicate keys are preserved and reported. Files and text stay in this page; they are not added to automatic storage or backups.


JSON difference
Paste or upload both inputs. Object key order is ignored; array positions are significant.
Paths use JSON Pointer notation: /items/0/name. Arrays are compared by index, not by item identity. Duplicate keys must be resolved before comparison. Editor contents are not automatically saved or included in backups.



Regex tester
JavaScript regular expressions. Test explicitly; patterns are not run while typing.
g = all matches; i = case insensitive; m = multiline anchors; s = dot includes newlines; u = Unicode; y = sticky. Match positions use UTF-16 units. Up to 500 matches; text up to 200,000 units; 2-second timeout. Replacement supports $&, $1, and named groups. Replacement output is capped at 2 Mi units.


URL / Base64
URL component encodes reserved separators. Full URI preserves separators such as : / ? &. Base64 supports emoji and Unicode text.
Base64URL uses - and _ without padding. Decoding accepts optional padding and whitespace but rejects invalid data or non-UTF-8 binary content. URL decoding does not turn + into a space. Input is limited to 2 Mi UTF-16 units.


JSON → CSV
Paste an array of records or select an array inside an object with /records.
Columns use escaped JSON Pointer paths. Arrays stay as JSON in a cell; null/missing fields are empty. Spreadsheet protection prefixes risky string cells with an apostrophe. JSON numbers retain their exact spelling; spreadsheets may still round them when importing as numbers.


Unix timestamp
Seconds may have up to 3 decimal places; milliseconds must be whole numbers. Date input always uses UTC; the timezone changes the displayed date only.



Text difference
Compare lines of text, logs, or code. Added and removed lines retain their line numbers.


CSV → JSON
Quoted fields, multiline cells, escaped quotes and CRLF are supported. Values stay strings unless detection is enabled. Large numeric tokens remain intact.

PDF toolkit
Set page order with ranges such as 3,1,5-7 or 4-2. Blank selects all pages; repeats duplicate pages. Move files up/down to change merge order. Encrypted PDFs are unsupported. Color & accessibility checker
The quick brown fox jumps over the lazy dog.
Accepts HEX, RGB, or HSL. Checks opaque sRGB color pairs against text contrast thresholds; this is not a complete accessibility audit. Click a palette swatch to copy its HEX value.


Interest rate solver
Compare another repayment scenario
Assumes equal monthly payments at month-end, a fully repaid balance, and no fees, insurance, balloon payment, or irregular dates. Nominal annual rate = monthly rate × 12; effective annual rate includes compounding. This is not an APR calculation.


Number to words
Plain decimal input, up to 15 integer digits and 2 decimal places. No rounding or currency conversion is performed.


Payment identifier validator
Checks syntax and available checksums only. It cannot confirm an account, bank, recipient, or payment destination exists. IBAN uses a bundled 89-country registry snapshot for length and national BBAN patterns, plus MOD-97 checksum checks.


Decision matrix
Scores range from 0 to 10; higher always means better. Weights are nonnegative and normalized automatically. For cost/risk, score lower cost/risk higher. Equal results remain tied.


Typing practice
Timer starts with your first character after Start. Speed uses five characters per word. Accuracy compares characters at matching positions. Paste/drop into the typing area is disabled during practice.


Expense splitter
Amounts use one currency and up to 2 decimal places. Omit shares for an equal split, or supply relative weights per participant. Rounding allocates every cent deterministically. Suggested settlements balance debts; they are not guaranteed to use the fewest transfers.


File inspector
Reads only the first 512 bytes for signature hints. Optional SHA-256 reads the whole file, up to 50 MB. This tool does not execute files or scan them for malware.


URL shortcuts
Shortcuts save in this browser when storage is available. Export JSON to move them between devices. Imports merge without replacing existing URLs. Only HTTP/HTTPS links are allowed; links open in a new tab without previews or tracking requests.


ZIP archive manager
Processing stays local. One selected file downloads directly; multiple selections download as a new ZIP. Unsafe paths, encrypted entries, symlinks, unsupported methods, ZIP64, and multi-disk archives cannot be extracted. Limits: 50 MiB ZIP input, 100 MiB expanded total, 2,000 entries; create up to 500 files / 100 MiB.


Flowchart builder
Add or edit nodes and connectors
Description syntax: nodeID [process|decision|start|end]: Label; connector: fromID -> toID : Label. This is a small dedicated diagram language, not a Mermaid parser. Click a node to edit it; drag nodes, or focus a node and use arrow keys to reposition it. Up to 150 nodes / 300 connectors.


Network & subnet calculator
IPv4 /31 uses point-to-point semantics; /32 represents one address. IPv6 has no broadcast. Split preview shows 64 child subnets per page, up to 65,536 children. This computes address ranges and does not probe a network.


Password & passphrase generator
Uses browser cryptographic randomness with unbiased index sampling. Passphrases use the bundled 7,776-word EFF list. Results are never saved in drafts, history, or backups. Clipboard contents may remain after this page is cleared.


Barcode generator
Barcode size & label
EAN/UPC accepts data digits without a check digit, or complete digits with a valid check digit. Black bars, white background, and quiet margins are retained. Valid encoding does not assign or register a retail product number.


Calendar event builder
Location, description & URL
Finite recurrence uses explicit dates, preserving local start time across clock changes. Nonexistent local times report an error; repeated local times use your selected policy. Month/year recurrences skip invalid dates. Up to 366 occurrences within 1970–2100. No invitations are sent.


Image color picker
Click the image to sample an original source pixel. Keyboard: arrows move the source pixel; Enter samples it. Palette colors are approximate, extracted from downsampled bins; pixels below 50% opacity are ignored. Click a swatch to copy HEX. Limits: 20 MiB / 20 megapixels raster input.
